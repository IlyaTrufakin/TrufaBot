# TrufaBot 📸🤖

Умный домашний медиа-сервер для Windows с интерактивным Telegram-ботом, фоновым режимом (System Tray), многоисточниковой файловой системой (NAS / локальные диски), гранулярным разделением прав доступа и будущей поддержкой локальной ИИ-классификации по расписанию (ONNX Runtime).

## 🏛 Архитектура
- **Язык**: C# (.NET 8)
- **Архитектурный шаблон**: Clean Architecture + DDD + MVVM
- **База данных**: SQLite (EF Core)
- **UI**: WPF + System Tray
- **Telegram**: Telegram.Bot (C#)
- **Безопасность**: 100% изоляция пользовательских данных в `%LOCALAPPDATA%\TrufaBot\`

## 🌟 Ключевые возможности
- 📁 **Проводник по архиву**: навигация по дереву каталогов NAS с пагинацией папок и файлов.
- 📸 **Альбомы предпросмотра**: быстрая генерация сжатых миниатюр на лету.
- 🎲 **Случайное фото**: выбор только среди фотографий (видео исключены) как по всему архиву, так и внутри конкретной папки.
- 🔒 **Гранулярный доступ**: персональная матрица прав к папкам для каждого члена семьи.
- 📊 **Журнал событий (Аудит)**: структурированное логирование с контрастным интерфейсом.

## 🚀 Сборка и запуск
1. Откройте `TrufaBot.slnx` (или `TrufaBot.sln`) в **Visual Studio 2026 / 2022**.
2. Соберите и запустите проект `TrufaBot.Presentation` (F5).
